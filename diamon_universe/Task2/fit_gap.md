## Список интеграций
### ИС «Алмазы» → ИС «Логистика»
<b>Тип:</b> Существующая
<b>Реализация</b>:
* <i>Промежуточное решение:</i> Ручная
* <i>Целевое решение:</i> Автоматическая

<b>Данные:</b>
+ Реестр алмазов - существующие
+ Ответственные - существующие
+ Маршрут - новый

### ИС «Лаборатория» → ИС «Аукцион»
<b>Тип:</b> Новая
<b>Реализация</b>:
* <i>Промежуточное решение:</i> Ручная
* <i>Целевое решение:</i> Автоматическая, выделенный защищенный канал

<b>Данные:</b>
+ Цифровой профиль алмаза - новый

### ИС «Лаборатория» → ИС «Бухгалтерия»
<b>Тип:</b> Новая
<b>Реализация</b>:
* <i>Промежуточное решение:</i> Ручная
* <i>Целевое решение:</i> Автоматическая

<b>Данные:</b>
+ Акт выполненных работ - новый
+ Номер партии алмазов - новый
+ Реквизиты - новый
