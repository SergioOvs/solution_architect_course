# Архитектурное видение для компании "Diamond Universe"

## Введение
<b>Цель документа:</b> Предоставить архитектурное видение для реализации нового, для компании "Diamond Universe", канала 
реализации алмазов - онлайн продажа, а также обеспечивающих процессов связанных с логистикой, ведением бухгалтерии и 
подготовкой алмазов к онлайн аукциону.<br><br>
<b>Область применения:</b> Документ описывает бизнес процесс "Продажа алмазов через онлайн аукцион". В бизнес процессе 
будут задействованы: ИС "Алмазы", ИС "Аукцион", ИС "Логистика", ИС "Бухгалтерия", ИС "Лаборатория", внешние облачные 
сервисы<br><br>
<b>Глоссарий:</b>

|      Термин      | Описание                                                                                                                                                                                              |
|:----------------:|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|   Лаборатория    | Компания-подрядчик, осуществляющая оцифровку алмаза                                                                                                                                                   |
| Карточка алмаза  | Сущность для покупателя, которая содержит информацию об алмазе, полученную от Лаборатории                                                                                                             |
| Оцифровка алмаза | Процесс оценки алмаза в Лаборатории включающий в себя оценку размера, чистоты, флуоресценции алмаза в ультрафиолете, внутреннего напряжения и трещины, формы и распределения включений в объеме камня |
                  
<br><br>
## Бизнес контекст и цели
<b>Бизнес-цели:</b> 
+ За 2 месяца организовать дополнительный и актуальный канал сбыта алмазов - онлайн аукцион, для сохранения и увелечения
своей доли на мировом рынке сбыта алмазов
+ За 1 год полностью автоматизировать и отладить процесс подготовки и проведения онлайн-аукциона, снизить риски 
зависимости от внешних сервисов, конкретных сотрудников, неэффективного использования ресурсов.

<b>Ключевые стейкхолдеры:</b>  
+ <b><i>Топ менеджмент компании "Diamond Universe"</i></b> - получить дополнительный и актуальный канал сбыта алмазов; 
увеличить объем продаж за счет появления нового канала сбыта; сократить время на продажи алмаза, так как появляется 
новый подход "1 оценка алмаза = несколько покупателей"; увеличить лояльность клиентов, так как появится процесс продажи 
алмазов "под ключ" (исключается этап оценки алмаза экспертом клиента).
+ <b><i>Покупатели, представители компаний из Индии, Китая и Бельгии</i></b> - сокращение расходов на услуги 
эксперта-оценщика, на командировку представителей покупателя в офис компании "Diamond Universe"; сокращение скорости 
принятия решения о покупке, так как результаты оценки независимой профильной лабораторией алмазов будут предоставлены 
продавцом.
+ <b><i>Обеспечивающие команды компании "Diamond Universe"</i></b> - прозрачный бизнес процесс с четким отслеживанием 
статусов алмазов; для бухгалтерии - прозрачный учет доходов и расходов.
+ <b><i>Подрядчик, в лице Лаборатории</i></b> - прозрачный документооборот (каждый заказ будет сопровождаться электронным
пакетом документов)

<b>Стратегические драйверы:</b> После пандемии 2020 года и закрытия ритейла, в мире появился новый тренд - переход 
бизнеса по продаже алмазов в онлайн. Компания Diamond Universe приняла стратегическое решение - для реализации алмазов 
организовать формат онлайн аукционов. Первый онлайн аукцион должен быть проведен через 2 месяца.

## Текущее состояние
<b>Обзор текущей инфраструктуры:</b> На текущий момент существующие процессы в "Diamond Universe" направлены на старую 
модель бизнеса - продажа через офлайн аукцион. Однако, в компании есть системы, которые обеспечивают следующие процессы:
автоматизированный учет драгоценных камней, автоматизированное проведение офлайн аукциона, перевозку камней по стране и 
за границу. ИТ-ландшафт компании состоит из ИС "Алмазы", ИС "Аукцион", ИС "Логистика", ИС "Бухгалтерия", которые после 
доработок могут быть использованы в целевом решении.
<b>Болевые точки:</b>
+ ИС в ИТ-ландшафте не реализую функционал онлайн канала продаж
+ Нет платформы для удаленного взаимодействия с покупателями (предоставление сведений об алмазах, онлайн аукцион)
+ Отсутствует бизнес процесс оцифровки алмазов у подрядчика и интеграция с ИС подрядчика.

## Целевое состояние
<b>Высокоуровневое описание решения:</b>
Бизнес процесс "Продажа алмазов через онлайн аукцион" состоит из следующих основных блоков:
1. Отбор алмазов для продажи онлайн в центральном офисе.
2. Перевозка алмазов в лабораторию, их оцифровка, и возврат обратно в офис. 
3. Публикация данных для покупателей, на основе которых будут приниматься решения. 
4. Проведение онлайн-аукциона. 
5. Отправка камней победителям торгов из офиса.

<b>Ключевые компоненты решения:</b><br>

| Компонент        | Группа                            | Описание                                                                                                     |
|:-----------------|:----------------------------------|:-------------------------------------------------------------------------------------------------------------|
| ИС "Алмазы"      | Основной бизнес                   | Отбор алмазов для цифрового аукциона, планирование работ, присвоение идентификаторов и подготовка ведомостей |
| ИС "Аукцион"     | Основной бизнес                   | Публикация карточки алмаза, проведение аукциона                                                              |
| ИС "Логистика"   | Внутренние обеспечивающие системы | Управление перевозкам в/из лаборатории и к покупателю                                                        |
| ИС "Бухгалтерия" | Внутренние обеспечивающие системы | Актирование и оплата услуг подрядчиков, ведение контрактов                                                   |
| ИС "Лаборатория" | Внешние обеспечивающие системы    | Оцифровка алмазов                                                                                            |

<b>Интеграционный ландшафт:</b> Обмен данных по защищенным каналам в автоматическом режиме по средствам API и/или 
Message Queue

## Архитектурные принципы и ограничения
<b>Основные принципы:</b>
+ Итеративный подход: Вывод MVP через 2 месяца с доработкой до целевого решения в течение 1 года
+ Минимальный "time-to-market" и минимум доработок для MVP
+ В целевом решении фокус смещается в пользу снижения рисков зависимости от внешних сервисов, конкретных сотрудников, 
неэффективного использования ресурсов
 
<b>Технические ограничения:</b> 
+ Для MVP:
  + Использование существующих ИС для планирования, логистики и проведения аукционов
  + Использование Excel файлы по утвержденным шаблонам, взамен полноценных интеграций между ИС
  + Использование внешних облачных инфраструктуры и сервисов для публикации данных для клиентов
+ Для целевого решения:
  + Отказ от Excel файлов в пользу полноценных интеграций между ИС
  + Выделение защищенных каналов для передачи конфиденциальной информации между ИС
  + Перенос внешней облачной инфраструктуры на внутренние сервера

<b>Стандарты разработки:</b> Используются существующие БД, и языки программирования существующих ИС.

## Нефункциональные требования
<b>Производительность:</b>
+ Система должна выдерживать пиковые нагрузки в режиме проведения онлайн аукциона без деградации функционала
<b>Масштабируемость:</b>
+ Система должна быть готова к росту регулярных участников аукциона на 15% от текущей клиентской базы
<b>Доступность:</b>
+ Облачные сервисы с карточками алмазов должны быть доступны на период проведения онлайн аукциона
<b>Безопасность:</b>
+ Защита конфиденциальных данных об алмазах и о клиентах на этапах хранения и информационного обмена между внутренними
и внешними ИС
+ Авторизация и аутентификация участников онлайн аукционов
<b>Зависимость от внешнего подрядчика:</b>
+ Формат, доступность системы, механизмы защиты канала связи и способ информационного обмена должен быть согласован 
с подрядчиком

## Дорожная карта реализации
### Этап 1. Разработка MVP
<b>Срок:</b> 2 месяца
<b>План работ:/b>
1. Доработка ИС "Аукцион" для проведения онлайн аукциона
2. Разработка и согласование Excel-шаблонов для публикации данных об алмазах, для получения данных получения результатов 
оценки от Лаборатории
3. Заключение договора с провайдером облачного сервиса и с Лабораторией
4. Публикация данных об алмазах в облачном сервисе
5. Разработка временного процесса актирования и оплаты услуг Лаборатории и провайдера облачного сервиса
6. Разработка временного процесса и Excel-шаблонов для передачи результатов аукциона в ИС "Логистика", ИС "Аукцион"

## Риски и допущения
<b>Риски:</b>
+ Возможная утрата знаний по legacy системам
+ Отсутствие финансов для организации серверов
+ Отсутствие возможности доработки со стороны внешней ИС "Лаборатория"
+ Утечка конфиденциальных данных при эксплуатации промежуточного решения
+ Несанкционированный доступ к Excel-файлам, используемых для интеграции между ИС
+ Человеческий фактор при работе с Excel-файлами: не внесение информации, утрата файлов 

<b>Допущения:</b>
+ Лаборатория обеспечивает в согласованные сроки качество оцифровке алмазов, не ниже очной оценки эксперта покупателя
+ Покупатели готовы доверять результатам оцифровки Лабораторией
+ Провайдер облачного решения обеспечивает необходимую защиту и доступность данных
+ Внутренние специалисты, привлекаемые к разработке обладают необходимыми компетенциями и знаниями
+ Внешние подрядчики готовы к доработкам или уже имею готовые механизмы для интеграций
+ Базы данных компании имеют запас, позволяющий реализовать целевое решение без существенного доумощнения
